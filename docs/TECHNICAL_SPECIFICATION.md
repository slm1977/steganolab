# Specifica v0.2
Static site. Canvas decodes opaque PNG, maximum 4 million pixels. Browser color management and conversion may affect RGB values of nonstandard PNG; use ordinary 8-bit RGB opaque PNG and verify round-trip before teaching. RGB only; alpha untouched. Payload UTF-8, no header, MSB-first within bytes, one selected bit per selected channel, row/column scan from (0,0). Capacity floor(width*height*channels/8). This exploratory protocol differs from previously proposed length-header protocol. Decoder requires explicit bit count and strict UTF-8. No authentication of payload. Difference map compares RGB only and requires equal dimensions. Synthetic missions are generated locally, not photographs. No live AI API, no automatic grading or protected teacher area. Future: exact PNG parser, browser tests, case export, synchronized tutor, improved zoom/navigation.
Independent controls for bit plane, extraction and encoder. Side-by-side views and grid overlay do not change pixel data. Byte preview limited to 512 bits; full sequence retained.
## v0.3
Monochrome masks must match cover dimensions; RGB sum >=384 maps to 1, otherwise 0. One bit per pixel in selected channel/plane, no header. XOR planes require equal dimensions. Arrow navigation clamps at edges. Plane PNG export contains actual rendered pixels, not grid overlays.
